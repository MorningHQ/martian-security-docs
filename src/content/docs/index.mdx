## Start with your workspace

Want a local preview first? [Try a free two-record SDK evaluation](/martian-security-docs/sdk/evaluations/) without a Martian account or model key.

New to Martian? [Accept your invitation and sign in](/martian-security-docs/get-started/access/), then read [the concepts](/martian-security-docs/get-started/concepts/). You need an agent connection that you are authorized to test. Each tutorial explains the role, setup and limits before you start.

## Choose the evidence you need

<div class="workflow-comparison">

| Your question | Use | What you receive |
| --- | --- | --- |
| Can an attacker steer this agent outside its intended rules? | Red teaming | A bounded assessment with recorded attempts, findings and verification evidence |
| Does this version answer a known set of cases correctly? | Evals | Dataset-version-pinned results, scores, comparisons and reviews |
| Should this tested revision pass my development checks? | SDK and CI | Local test results, retained reports and a recorded gate outcome when configured |

</div>
